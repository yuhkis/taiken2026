# 授業サイト（2026-08-21 体験授業）

このフォルダをそのまま静的ホスティングに置けば、スライドと教材がすべて動きます（サーバ処理・外部CDN依存なし）。
`file://` で直接開いても、スライド・埋め込み教材・貼って実行のすべてが動きます（ネット接続不要）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 授業ボード（入口）。教材へのリンクと注文文のコピー |
| `slides.html` | 本番スライド（27枚・数式/グラフ入り大学版）。矢印キー／画面右下の‹›／スワイプで進行。`#番号` で直接ジャンプ（例 `slides.html#18` = 演習ボード） |
| `sim-tsugi-no-kotoba.html` | 教材① 次の言葉ガチャ（次トークン予測・温度） |
| `sim-kotoba-no-chizu.html` | 教材② ことばの地図（単語ベクトル） |
| `hatte-jikkou.html` | 教材③ 貼って実行ページ（コード実行・予備経路） |
| `kansei/` | 完成コードの実物（もぐらたたき／おみくじ／反応速度） |
| `assets/` | 画像（ロゴ・QR・写真） |

## ホスティング（GitHub Pages の例・約5分）

```bash
git init && git add -A && git commit -m "2026 taiken jugyo site"
gh repo create taiken2026 --public --source=. --push
```

または GitHub の Web UI で新規リポジトリ → このフォルダをアップロード → Settings → Pages → Branch: main で公開。
公開URL例: `https://<ユーザー名>.github.io/taiken2026/slides.html`

## 再利用について

**HTML／CSS／JavaScript（`*.html` と `kansei/`）は、学校・他校での再利用・改変ともに自由です。**

ただし **`assets/` 内の画像は対象外** です。大学の公式ロゴ、研究の記録写真、第三者のサービス画面などを含み、
著者が再許諾できる範囲を超えるためです。流用される場合は画像を差し替えてください。

## 補足

- `hatte-jikkou.html` は貼られたコードを `iframe sandbox`（`allow-same-origin` なし）で実行する。
  このページ自身はコードをどこへも送信しないが、**貼られたコードが外部へ通信することは防げない**点に注意。
- スライドは1024×768（4:3）基準で拡縮。プロジェクタが16:9でも黒帯が出るだけで崩れない。
- 全HTMLに `<meta name="robots" content="noindex, nofollow">` を入れている（検索結果に出さないため）。
